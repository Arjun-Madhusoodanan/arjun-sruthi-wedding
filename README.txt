(or deploy it through another static host). Keep all assets together.

IMPORTANT: WHATSAPP LINK PREVIEW
WhatsApp commonly requires an ABSOLUTE HTTPS og:image URL. After publishing,
edit index.html, find:
  <meta content="assets/whatsapp-preview.png" property="og:image"/>
and replace only the content value with the actual address of the hosted image,
for example https://YOUR-SITE.netlify.app/assets/whatsapp-preview.png
If your host provides caching, WhatsApp may take time to refresh previews.
